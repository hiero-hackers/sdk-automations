# 7.2 — Hold every captured webhook to the shape the normalizer reads

**Customer:** `packages/core/src/engine/normalize/` and the captures in `packages/dev/testkit/fixtures/`.
A capture describes the GitHub of the day it was taken; this protocol asks the GitHub of today the
same question, without a receiver or a tunnel.

**Instrument:** `src/probes/events.ts` (the shapes) and `src/probes/webhooks.ts` (the pass), run as
the second half of `pnpm lab:probe`. Offline, `test/webhooks.test.ts` holds the pass to a scripted
log.

## Procedure

1. As the installation, provoke each shape in order on the sandbox: open an issue, label it,
   comment on it, close it; close and reopen the pull request `SANDBOX_EVENTS_PR` pins. The
   `reopened` delivery stands in for an `opened` nobody can repeat.
2. As the App, read `GET /app/hook/deliveries` until each provoked delivery is listed, then its
   payload by id. Match on event, action and the item number.
3. Hold the payload to the shape's paths (`missingFields`) and its action. Stamp the verdicts as
   `webhooks` in `probe-results.json`; `conformance.test.ts` requires one per capture, clean.
4. Each payload is scrubbed and written to `evidence/pending/<event>.<action>.json`. Promotion to the
   testkit stays 7.1's human step; a promoted capture's `capturedAt` moves with it.

## Exit

Every capture has a clean `webhooks` result inside the 45-day window. First run: owed.
